Deployment strategy

In the root directory of your Node.js project, create a file named Dockerfile (no extension, capital 'D'). 
Add the following content, which uses a multi-stage approach for an optimized image 

# Stage 1: Build environment (install dependencies) 
FROM node:20-alpine AS build 
WORKDIR /app 
COPY package*.json ./ 
RUN npm install --only=production 
 
# Stage 2: Production environment (copy only necessary files) 
FROM node:20-alpine 
WORKDIR /app 
COPY --from=build /app/node_modules ./node_modules 
COPY . . 
EXPOSE 3000 
CMD ["npm", "start"] 

Step 2: Create a .dockerignore file   

In the same root directory, create a file named .dockerignore to prevent unnecessary files and local development dependencies (like node_modules and .git files) from being copied into your Docker image. This improves build speed and security 

node_modules 
npm-debug.log 
.git 
.gitignore 
.env 
build 
dist 
*.md 

Build the Docker Image  

Open your terminal in the project's root directory and run the following command to build the Docker image. 
The -t flag tags your image with a name (e.g., my-node-app 

docker build -t mitram-tourism-backend .

 

Step 4: Run the Docker Container   

Once the image is built, run your container using the docker run command. The -p flag maps a port on your host machine to a port inside the container (e.g., host port 80 to container port 3000) 

docker run -p 80:3000 my-node-app 

Your Node.js backend should now be running inside a Docker container. You can access it in your browser or with a tool like Postman at http://localhost:80 

To run the container in the background (detached mode), add the -d flag to the command:   

docker run -d -p 80:3000 my-node-app
