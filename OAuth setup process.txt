LocalStack setup :-

Open a Command Prompt: Launch your command prompt or PowerShell.
Run the LocalStack Docker Command: 
Enter the following command and press Enter to start the LocalStack container:

docker run --rm -it -p 4566:4566 localstack/localstack

1. Wait for Download and Startup: The first time you run this command, it may take a few minutes to download the Docker image. Once downloaded, LocalStack will start within the container. 
2. Verify Installation: Once the logs show that LocalStack is running, you can verify it by configuring your AWS CLI to use LocalStack. 



1. Install the AWS CLI: If you don't have it installed, download and run the AWS CLI Installer for your environment. 
2. Set the Endpoint URL: Configure your AWS CLI to point to the LocalStack endpoint. 
You can do this by setting an endpoint URL for your AWS CLI commands: 

aws --endpoint-url=http://localhost:4566 s3 ls

This command lists the S3 buckets in your LocalStack environment.
